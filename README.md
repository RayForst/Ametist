# Ametist - Markdown Editor with Graph Visualization

A simple markdown editor with graph visualization, inspired by Obsidian. This application allows you to create and edit markdown files while visualizing the connections between them in a graph view.

## Features

- Edit markdown files
- Visualize connections between files using a graph
- Create new markdown files
- Open and manage folders of markdown files
- Real-time graph updates based on file connections

## Installation

1. Make sure you have [Node.js](https://nodejs.org/) installed
2. Clone this repository
3. Install dependencies:
```bash
npm install
```

## Running the Application

To start the application in development mode:
```bash
npm start
```

## Usage

1. Click "Open Folder" to select a directory containing your markdown files
2. Click on any file in the sidebar to edit it
3. Create new files using the "New File" button
4. Use double square brackets `[[]]` to create links between files
5. The graph view will automatically update to show connections between files

## Development

To run the application in debug mode:
```bash
npm run dev
```
